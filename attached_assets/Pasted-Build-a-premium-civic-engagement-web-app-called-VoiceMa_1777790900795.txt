Build a premium civic engagement web app called “VoiceMap Civic: Public Voice & Representative Portal.”

Purpose:
A free public-interest platform that helps people find representatives, understand issues, express where they stand, create petitions, send responsible messages, and track whether officials respond. The goal is to boost public access and prevent representatives from claiming they did not know where constituents stood on important issues.

Important:
This app should not be partisan. It should be issue-centered, transparent, and focused on public accountability.
Use neutral civic language:
- “constituent position”
- “public sentiment”
- “issue response”
- “representative accountability”
- “petition support”
- “official response tracking”

Design style:
Use a premium MacOS Tahoe / Apple Liquid Glass inspired UI:
- glassmorphism cards
- frosted translucent navigation
- luminous moving orbs in the background
- glowing borders on cards/buttons
- soft animated gradients
- modern civic dashboard look
- dark navy/cyan/aqua with white glass
- subtle gold accents for government/civic sections
- rounded cards
- clean infographic / visual roadmap sections
- bold title/subtitle
- simple icons
- professional and trustworthy

Tech:
React + Vite + Tailwind.
Use localStorage for version 1.
No paid APIs.
No backend yet.
No real representative lookup API required for version 1; use placeholder data and structure for later integration with Google Civic API or other public data.
Make code modular.

- name
- office/title
- district

- recent actions placeholder
Allow filtering by:

Allow searching by name or district.

Issue Voting Center:
Create issue cards with:
- issue title
- short plain-language summary
- why it matters
- possible positions:
  - support
  - oppose
  - unsure
  - needs more information
- public sentiment bar
- district/locality selector placeholder
- comment field
- “Generate message to representative” button

Important feature:
Show a statement like:
“Public sentiment shown here is based on submitted responses and should be interpreted as community feedback, not a scientific poll unless verified methods are added.”

- Petition title

- Supporter statement
Generate:

- email version

- Representatives contacted

Good Actions Spotlight:
Highlight positive actions by officials:
- introduced helpful legislation
- responded to constituents
- supported public welfare
- helped animals/health/access/etc.
- improved transparency
The goal is not only criticism; it also rewards good public service.

About / Trust / Privacy:
Include:
- This platform is nonpartisan.
- It helps organize public input.
- It does not claim to be a scientific poll unless verification is added.
- Users should be truthful and respectful.
- The app should avoid harassment and spam.
- Explain future verification options:
  - district verification
  - duplicate prevention
  - transparent methodology
  - public audit trail
